### 2026-11-17 電子レンジの扉：カメラで扉の角度を見て、Unity の扉も同じだけ開くようにした（試し）

- 決まったこと（仮）：

- やったこと（Unity）：
  - `ScreenEvent` に `Open`・`Angle`、`EventNames.Door`、`EventRouter.OnDoor`、`LocalEventSender.Door`・`DoorAngle`、キー `M`（扉を開け閉め）
  - `MicrowaveDoorView`（新しい）：`angle` が届いたらその角度まで（0〜110 度）、`open` だけなら 100 度 / 0 度。`reset` で閉まる。0.15 秒くらいで追いつく

  - テスト：EditMode に扉の JSON（open・angle）、PlayMode に `MicrowaveDoorTests`（開く・閉まる・角度まで開く・reset で閉まる）
  - README にキー M・扉・スクリプトを書いた
- やったこと（カメラ。`camera/` はカメラ担当のフォルダーだが、ユーザーに頼まれた。今ある `camera/` のファイルは変えていない）：

    - 扉の角度：扉を閉めたときの映像を覚えておき、今の映像との「ちがい」を見る。蝶番から角度を変えながら帯を引き、ちがいがいちばん多い向き（同じくらい高い点数が並ぶ範囲の真ん中）を扉の向きにする。台も扉も木なので、色では見分けられない（はじめは木の色で探したが、キッチン台にのせたら使えなくなった）
