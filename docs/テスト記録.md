# テスト記録

テストのやり方と結果を、新しいものを上に書き足していく。
「何をどう試して、何が分かり、何がまだ確かめられていないか」を残す。

## テストのやり方

### Mac 上のテスト（実機なし）

振り判定・つまみ判定を合成データで確かめる。判定のコード（`device/src/shake.cpp`、`knob.cpp`）を変えたら必ず実行する。

```sh
sh device/host_test/run.sh          # 全部 OK なら終了コード 0
```

| テスト | 確かめること |
| --- | --- |
| `shake_test` | 1 回振って 1 回、ゆっくり・速く・強く 10 回振って 10 回、立てたまま・水平では 0 回 |
| `knob_test` | 回した角度で切・弱・中・強が決まる、境目でばたつかない、平置きでは角度を出さない、起動直後に段階が変わらない |

### 実機の記録

1. 書き込む（`device/README.md` の「書き込む」）
2. 記録を始めてから、リセットボタンを短く押して起動する

```sh
uv run --with pyserial tools/device_record.py 記録.txt --seconds 240
```

3. 決めた手順どおりに動かす。動作の区切りでは 5 秒止まる（記録の上で区切りが分かるように）
4. 記録を判定にもう一度通す（しきい値を変えたときの比較）

```sh
sh device/host_test/run.sh          # replay もここでビルドされる
device/host_test/build/replay 記録.txt
```

記録ファイルは大きいので git には入れない。結果の数値をこのファイルに書く。

## 記録

### 2026-09-30 つまみ判定（実機）

- 本体：M5StickS3 `AC:27:6E:D3:5C:3C`、つまみ判定を入れた最初の版（起動直後の不具合を直す前）
- 手順：画面を正面に向けて手で持ち、つまみのように両方向にゆっくり回す・戻すを約 4 分。生データも記録
- 結果
  - 回すと `OFF → LOW → MID → HIGH`、戻すと逆順に変わった。逆回しも同じ
  - 段階が変わった角度：上げるとき 30・75・120 度、下げるとき 22・67・112 度（設計どおり）
  - 静かに持っているときの角度の揺れ：0.5 秒ごとの幅で、下位 25% が 0.4 度
  - 境目での行き来は、毎回 9〜80 度実際に動かしていた（ばたつきではない）
  - 強く回したときに、振りを 1 回誤って数えた（強さ 0.01、傾き 55 度）。つまみの役割のデバイスでは、サーバーが振りを無視すれば問題ない
- 見つかった不具合（コードは直した。**実機ではまだ確かめていない**）
  - 起動直後に一瞬 `HIGH`（179 度）を出した → ローパスを最初のサンプルで初期化するよう直した
  - 「切」の位置が未保存のとき、起動時にエラーログが 1 行出た → 保存済みか確かめてから読むよう直した
- まだ確かめていないこと
  - ボタン A 長押しで「切」の位置が合うか（画面で確認する）
  - 実際のおもちゃのつまみに貼った状態での確認

### 2026-09-28 振り判定 2 回目：すぐ数える版（実機）

- 本体：同上。判定は「45 度以上傾いてピークが来たらすぐ数える。数えてから 250ms は数えない」
- 手順：「1 回だけ振る → 10 回振る → 持ち上げて置く 5 回 → 弱めに 10 回」を伝えて、約 1 分 20 秒動かしてもらった。生データも記録。手順どおりだったかと、手元で数えた回数は記録していない
- 結果
  - 数えた振り：51 回。振っていない時間（約 2 分 40 秒）の誤カウントは 0 回
  - 加速度のピーク（1.8g 超）：99 個。うち 45 度以上傾いていたもの 63 個
  - 63 個とも、注ぎ口と逆向き（Y がマイナス、約 -8g でセンサーの上限に張り付く）だった。1 振りで強いピークは 1 つだけ出る
  - 63 個のうち 12 個は、直前のカウントから 199〜239ms 後に来たため 250ms の壁で落としていた。前後と約 250ms 周期で並んでおり、速く振ったときの本物の振り
- 対応：壁を 120ms に縮め、注ぎ口と逆向きのピークだけ数えるようにした。同じ生データを通すと 62 回（落としたのは 20ms 差の小さなピーク 1 個だけ）
- まだ確かめていないこと
  - この判定での、回数を数えながらの実機テスト（要件定義書 8.2「振り 10 回で 10±1 回」）
  - 持ち上げの誤検知（要件定義書 8.2「持ち上げ 20 回で誤検知 1 回以下」）

### 2026-09-28 振り判定 1 回目：繰り返しを条件にした版（実機）

- 判定：45 度以上傾いて、ピークが 0.7 秒以内に繰り返したら数える（1 回目は保留）
- 結果：振りがほぼ同時刻の 2 件ずつまとめて出た。1 回だけ振ると数えられない
- 対応：「1 回振ったら 1 回すぐ数える」に変更し、要件定義書 5.2 も書き換えた
