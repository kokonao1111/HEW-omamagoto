# 自前モデル（YOLO）の作り方

スマホで撮ったおもちゃの写真から、野菜・包丁を「位置つき」で見つける検出モデルを作る手順。

## 1. 写真を撮る

- **1枚に対象1つ**、机の上などシンプルな背景で
- 連写OK。ただし連写のたびに **角度・距離・向き・持ち方** を変える（同じ写真が100枚あっても意味がない）
- 目安: **1つの物につき 50〜150 枚**
- 展示する場所・照明で撮ると一番効く
- 包丁は「手で持った状態」も混ぜる（本番は手で持っているので）
- おまけ: 何も置いていない机・手だけ・腕だけ の写真を 20〜50 枚（誤検出を減らす）

## 2. フォルダに入れる

AirDrop などで Mac に送り、**フォルダ名 = クラス名** にして入れる:

```
dataset/raw/
  にんじん/     IMG_0001.jpg IMG_0002.jpg ...
  きゅうり/
  包丁/
  _background/  ← 何も無い机・手だけ など（ラベル無しで学習に混ぜる）
```

HEIC のままで大丈夫（自動で読める）。

## 3. 自動で枠を付ける

```sh
.venv/bin/python train/auto_label.py
```

`dataset/preview/<クラス名>/` に枠を描いた画像が出るので、ざっと目で確認。
赤い枠（枠付けに失敗して画像全体になったもの）が多いクラスは、背景がごちゃごちゃしているか対象が小さすぎるので撮り直す。
対象が画面いっぱいに写っている写真ばかりなら `--full` を付ければ枠付けをスキップできる。

## 4. 学習して書き出す

```sh
.venv/bin/python train/train.py
```

M1/M2 Mac で 300 枚・60 epoch なら 10〜20 分くらい。終わると

- `models/best.onnx` … ブラウザで動くモデル
- `models/model.json` … 入力サイズとクラス名の一覧

（学習前は COCO 学習済みの yolov8n が仮に入っている。`knife` クラスがあるので包丁だけは試せる）

が出る。ブラウザをリロードして **詳細設定 → 検出方法** を「自前モデル(YOLO)」にすると使える。

## 5. 精度が足りないとき

- 最後に出る `mAP50` が 0.9 未満なら写真のバリエーション不足。苦手な角度・照明を追加で撮って 3 からやり直す
- `--epochs 100` に増やす
- `--model yolov8s.pt` にすると精度が上がるが、ブラウザでの速度は落ちる

## 環境の作り直し

```sh
/opt/homebrew/bin/python3.12 -m venv .venv
.venv/bin/pip install ultralytics onnx onnxruntime onnxslim pillow-heif
```
