# センサーデバイス（ESP32 / M5StickS3）

調味料容器やコンロのつまみに付ける M5StickS3 のファームウェア。振りとつまみの回転を検知して JSON を出す。
要件定義書の 5.1〜5.2、5.4、6.2、6.6 に対応する。

全デバイスが同じファームで動き、役割（塩・こしょう など）はサーバーが MAC アドレスで決める（要件定義書 5.9）。
イベントは 1 行 1 JSON で、BLE と USB シリアルの両方に出す。BLE ではデバイスが周辺機器になり、展示用 PC（サーバー）が接続しに来る。

## 準備（初回だけ）

```sh
uv tool install platformio          # pio コマンドが入る（~/.local/bin）
```

`pio` が見つからないときは `export PATH="$HOME/.local/bin:$PATH"` を `~/.zshrc` に足す。

## 書き込む

M5StickS3 はパソコンからの自動リセットで書き込みモードに入れない。毎回ボタンで入れる。

1. USB でつなぐ
2. 側面のリセットボタンを約 2 秒長押しし、中の緑 LED が点滅したら離す（書き込みモード）
3. 書き込む

```sh
cd device
pio run -t upload                   # ビルドして書き込む
```

4. 書き込み後、もう一度リセットボタンを短く押すとファームが起動する
5. シリアルを見る

```sh
pio device monitor                  # 終了は Ctrl+C
```

## 画面

| 表示 | 意味 |
| --- | --- |
| 1 行目 | MAC アドレス。サーバーの設定（要件定義書 6.5 の `[roles]`）に書く |
| `bat` | バッテリー残量。`chg` は充電中 |
| `tilt` | 注ぎ口の傾き（度）。水平が 0、真下が 90。45 以上で緑になる（振りを数える角度） |
| 大きい数字 | 振った回数。ボタン A（正面の大きいボタン。実機で要確認）を押すと 0 に戻る |
| `last` | 最後の振りの強さ（0〜1） |
| `knob` | つまみを「切」の位置から回した角度（度）。画面が上か下を向いているときは `---` |
| `OFF` など | 火の強さ（`OFF`・`LOW`・`MID`・`HIGH`） |
| `omamagoto-…` | BLE での名前（MAC アドレスの下 4 桁） |
| `BLE connected` / `BLE waiting` | サーバー（または確認ツール）とつながっているか |

## BLE で受け取る（要件定義書 6.6）

サーバーができる前は、確認ツールでデバイス側の BLE を確かめる。近くにある `omamagoto-` のデバイスを全部探してつなぐ。

```sh
uv run --with bleak tools/ble_monitor.py
```

- 切断・再接続を時刻付きで表示する。`seq` が飛ぶと取りこぼしとして知らせる
- macOS では、初回にターミナルへの Bluetooth の使用許可を求められる
- JSON 1 行を改行付きで送る。1 回の通知に入らなければ分けて送るので、受け取る側は改行までつなげる

## 出す JSON（要件定義書 6.2）

```json
{"event":"hello","board":26,"imu":true,"device":"AC:27:6E:D3:5C:3C","ts":812,"seq":1}
{"event":"battery","percent":100,"device":"AC:27:6E:D3:5C:3C","ts":815,"seq":2}
{"event":"shake","intensity":0.42,"tilt":71,"device":"AC:27:6E:D3:5C:3C","ts":15230,"seq":3}
{"event":"knob","level":2,"angle":82,"device":"AC:27:6E:D3:5C:3C","ts":20410,"seq":4}
```

- `hello` は起動時に 1 回。`board` は M5Unified の機種番号（26 = StickS3）
- `battery` は起動時と 30 秒ごと
- `knob` は火の強さの段階が変わったときだけ。`level` は 0=切・1=弱・2=中・3=強
- `ts` は起動からのミリ秒

## 振りの判定（src/shake.cpp）

注ぎ口が水平より 45 度以上下を向いているときに、加速度のピーク（1.8g 超）が来たら、その場で 1 振りと数える（要件定義書 5.2）。
持ち上げただけの揺れは、注ぎ口が上を向いているので数えない。

実測（2026-09-28、画面の上側を注ぎ口にして手で振った）では、1 振りで強いピークが 1 つ、注ぎ口と逆向き（Y がマイナス、約 -8g でセンサーの上限に張り付く）に出た。
逆向きのピークだけを数えるので、振り出しと止めを 2 回と数えることはない。念のため、数えてから 120 ミリ秒は次を数えない（速く振っても 1 振りは 200 ミリ秒ほどある）。

しきい値は `src/shake.h` の `ShakeConfig`。将来はサーバーの設定から変えられるようにする。

調整するときは、シリアルに `r` を送るとセンサーの生データ（`raw,ts,ax,ay,az,tilt`、加速度は g）が流れる。もう一度 `r` で止まる。

注ぎ口の向きは今は「画面の上方向（USB と反対側）」にしている。容器への入れ方が決まったら `setSpoutAxis()` で変える。

## つまみの判定（src/knob.cpp）

正面に付いたつまみに、画面を正面に向けて貼る（要件定義書 5.4）。
回すと画面の中で重力の向きが変わるので、その角度から「切」の位置から何度回したかを出す。左右どちらに回しても同じに扱う。

| 角度 | 段階 |
| --- | --- |
| 30 度未満 | 切（`OFF`） |
| 30〜75 度 | 弱（`LOW`） |
| 75〜120 度 | 中（`MID`） |
| 120 度以上 | 強（`HIGH`） |

戻すときは、境目より 8 度余計に戻したら段階を下げる（境目で段階がばたつかないようにする）。
しきい値は `src/knob.h` の `KnobConfig`。

### 「切」の位置を合わせる

貼り方で 0 度の位置が変わるので、つまみに貼ったら一度だけ合わせる。

1. つまみを「切」の位置にする
2. ボタン A を長押しする（画面の `knob` が 0 になる）

合わせた位置は本体に保存されるので、電源を切っても残る。

## テスト

判定のコードを変えたら、Mac 上のテストを実行する（実機なし）。

```sh
sh device/host_test/run.sh
```

実機での確かめ方と、これまでの結果は `docs/テスト記録.md` にまとめている。

## 元の UiFlow2 に戻す

M5Burner で StickS3 用の UiFlow2 を書き込む。
最初の 1 台（`AC:27:6E:D3:5C:3C`）は書き換える前の Flash 全体を `device/backup/` に保存してある（git には入れない）。戻すときは書き込みモードにして次を実行する。

```sh
pio pkg exec -p tool-esptoolpy -- esptool.py --chip esp32s3 --before usb_reset write_flash 0 backup/sticks3_uiflow2_ac276ed35c3c.bin
```

## まだ無いもの

- しきい値をサーバー設定から変える仕組み
- フライパン用の傾き（`tilt`）イベント、レンジ用の入力
- 実機でのつまみの確認（つまみに貼って回す）
- 実機での振り判定の調整（要件定義書 8.2 の「振り 10 回で 10±1 回」「持ち上げ 20 回で誤検知 1 回以下」）
